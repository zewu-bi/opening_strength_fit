# 全 A 1m 路径 TCN 涨停延续诊断

该实验只使用 1m 已实现收益的全日截面排名路径，屏蔽 10m/60m 通道，在全 A 股票上训练、
验证和测试 plain TCN。它是价格路径/动量基准，不包含 opening incumbent score、竞价或盘口特征，
不能作为 opening-strength 延续证据。2026-07-28 的逐行预测复核进一步确认，其 Top100 收益主要
来自 D 日已经涨停的股票；本页据此把该 run 从“广义全天强势延续候选”重新定性为
“尾盘涨停延续诊断/理论上界”。

## 固定口径

- 输入：`alpha_return_1m` 截面排名及有效性 mask；最晚时钟 `14:47`；
- 屏蔽：10m/60m 的最晚时钟均设为 `00:00`；
- universe：`train_universe = evaluation_universe = all_a`；
- 模型：plain residual TCN、MSE、hidden width 64；
- 训练目标：当日全 A 原始 D→D+1 收益的 centered rank，日截面均值为 0；
- 收益评价：用原始 D→D+1 收益计算 Top100 return、全池 return 及两者之差；
- 窗口：前 36 个月中前约 33 个月拟合、最后 3 个月验证，随后测试 6 个月；
- OOS：2022H1 至 2025H2，共 8 folds、969 个交易日；
- 选择：每日全 A score Top100，相对当日全 A 均值；
- 镜像：`sha256:8a16ba894e9b9a6496ad487313116770e3bd3ae5357bb1258d1a80da5974bc91`。

## 结果

| universe | 日均 Rank IC | Top100 return | 基准 return | Top100 excess | 正半年 | 正月份 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 全 A | 0.091529 | 98.06 bps | 4.49 bps | **93.57 bps** | 8/8 | 48/48 |
| pool_L 诊断 | 0.066973 | 54.41 bps | 11.92 bps | **42.49 bps** | 8/8 | 47/48 |

全 A Top100 excess 的日中位数为 `83.52 bps`，850/969 日为正。单边逐日 P95/P99
upper-tail cap 后分别为 `35.12/84.57 bps`，说明原始均值明显依赖最右侧 5% 收益，但不完全由
最右侧 1% 驱动。以上均为等权、未扣成本、未做容量和真实收盘竞价成交约束的研究指标。

`4.49 bps` 和 `11.92 bps` 分别是全 A、`pool_L` 每天先对股票等权、再对 969 天等权得到的
**原始收益**，不是池内超额。整个池子相对自身的超额按定义恒为 0；因此全 A / `pool_L` Top100
池内超额分别为 `98.06 - 4.49 = 93.57 bps` 和 `54.41 - 11.92 = 42.49 bps`。将 D→D+1
目标挂在 feature date D 是监督标签对齐，不会产生这两个非零原始收益背景。

## 2026-07-28 涨停归因

复核使用实际 8-fold OOS prediction，共 `4,837,650` 行、`969` 日、`5,351` 个 symbol，且
`date × symbol` 无重复。D 日收益严格由前一交易日 prediction 中的 D−1→D target 对齐，不使用
“同股票上一条可用记录”代替交易日映射。

涨停状态使用近似日线规则识别：主板 D 日收益 `>=9.5%`，创业板/科创板 `>=19.5%`。该规则用于
归因而非精确交易状态；它未完整覆盖研究期内 ST 5%、IPO/重新上市特殊规则和逐分价格舍入，因此下表
称为“涨停附近”。在 Top100 被标记的样本中，约 `93.7%` 的 D 日收益落在名义 10%/20% 涨停幅度
的 `±0.1` 个百分点内，结论不是宽阈值误删普通大涨股造成的。

| 诊断 | 结果 |
| --- | ---: |
| 全 A 涨停附近股票—日 | `58,705` |
| 可对齐的 968 日内，每日涨停附近股票数均值 | `60.65` |
| 涨停附近股票 D+1 pooled 原始收益 | `201.59 bps` |
| 每日先等权、再跨日平均 | `186.57 bps` |
| Top100 中涨停附近股票—日 | `32,542` |
| Top100 每日涨停附近股票数均值/占比 | `33.58 / 33.58%` |
| 模型选中涨停附近股票 D+1 原始收益 | `261.51 bps` |
| 全 A 当日涨停附近股票被 Top100 选中比例 | `55.43%` |
| 涨停附近股票对 Top100 return 的贡献 | `87.82 bps` |
| 非涨停附近股票对 Top100 return 的贡献 | `10.24 bps` |

因此，涨停附近股票贡献了全 A Top100 `98.06 bps` 原始收益的约 `89.6%`。这解释了为什么事后
移除该组后结果大幅下降：

| universe / 处理 | Top100 return | 原全池 base | 相对原全池 excess | 同过滤池 base | 相对同过滤池 excess |
| --- | ---: | ---: | ---: | ---: | ---: |
| 全 A 原始 | `98.06 bps` | `4.49 bps` | `93.57 bps` | — | — |
| 全 A 剔除涨停附近并按 score 补足 100 只 | `14.97 bps` | `4.49 bps` | `10.48 bps` | `2.21 bps` | `12.76 bps` |
| `pool_L` 原始 | `54.41 bps` | `11.92 bps` | `42.49 bps` | — | — |
| `pool_L` 剔除涨停附近并按 score 补足 100 只 | `10.10 bps` | `11.92 bps` | `-1.82 bps` | `10.10 bps` | `≈0.00 bps` |

相对原全池的 `10.48/-1.82 bps` 是保持原 benchmark 不变的反事实压力测试；如果正式把候选池改成
非涨停过滤池，则应使用同一过滤池的 base，此时池内 excess 为 `12.76/≈0.00 bps`。无论采用哪种
比较，该过滤都只是 post-hoc 诊断，不是非涨停模型的公平成绩。当前模型和 validation epoch 本来就
围绕涨停延续优化；要评价普通强势延续，必须在训练前定义可交易非涨停 universe、在该 universe 内
重算 target rank，并重训全部 8 folds。

## 形成捷径的机制

首轮 all-A run 的输入同时包含每分钟 1m return 截面 rank 和有效性 mask。连续上行、冲板以及封板后
长时间平坦/无有效 ask1 短标签的组合，足以编码 D 日涨停状态。训练资格只要求股票当天
`time_valid.any(axis=1)`，而日频 target 只要求 D、D+1 有有效收盘价；它不要求 `14:47` 或收盘集合
竞价时仍有卖盘、深度或真实成交。validation 又直接按 Top100 excess 选 epoch，因此模型会优先使用
这一最强且最容易识别的状态。

这不是已发现的日期泄漏：训练/验证/测试窗口无重叠，目标严格映射到下一交易日，输入中未发现直接
包含 D+1 target。问题是研究任务和入场资格不一致，导致模型把“已经涨停”当作广义强势延续的捷径。

## 决策

该 run 不晋级为收盘新开仓策略，也不再作为“广义全天强势延续”结果引用。它保留三种用途：

1. 2022–2025 涨停后 D+1 条件收益及模型二次筛选的诊断；
2. 已有持仓在 `14:47` 的隔夜留仓/减仓研究上界；
3. 提前入场模型的 late-information 对照。

后续将涨停作为**买入后的可能结果**，而不是信号时已经发生的筛选条件。普通强势延续路线应比较多个
更早的决策时点，只使用时点前信息，要求实际 ask/status/depth 可入场，并将 target 改为
`实际入场价(t)→D+1 可执行退出价`。信号时已经封死的股票从普通候选池移出；信号后才涨停的股票保留
为预测成功。涨停延续本身另立子任务，使用排队、封单、后续卖出成交量和未成交现金模拟。

旧 `09:31-09:40` opening policy 不能仅因使用实际 ask1 标签就假定没有同类问题。开盘集合竞价即可
形成涨停，且现有执行配置没有正的 `min_limit_up_room_bps`。需要按 decision clock 重新归因
“信号时已封死 / 仍有卖盘 / 后续才涨停 / 始终未涨停”四组，确认 opening excess 主要来自可提前买入
后才涨停的股票，而不是信号时已经不可成交的股票。
