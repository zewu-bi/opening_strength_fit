## 结论

- 随窗口后移，涨停依赖在绝对贡献和贡献占比上都持续下降。Baseline 1m 的收盘涨停贡献占比从
  09:31 的 `24.04/18.07 = 133%` 降至 11:01 的 `5.37/7.62 = 70%`，14:01 仅约 `20%`；
  超过 100% 表示非涨停股票对总超额有负贡献。
- 11:01 无涨跌停训练已接近中性选股：1m/3m 的实际涨停富集为 `1.19x/1.05x`，同时对应
  label 总超额为 `7.82/8.01 bps`，没有因去掉涨跌停训练样本而下降。
- 11:01 的短期 label 本身不依赖涨停：无涨跌停 1m/3m 的涨停贡献仅占总超额约 `3.1%/4.0%`；
  收盘归因仍有 `42.6%/34.1%` 来自最终涨停，反映短期强势与后来涨停的真实相关性。
- 四窗口共同支持“临近开盘时模型更容易利用涨停状态捷径”的解释。删除约 `2.7%` 训练样本能显著
  改变涨停偏好，却没有破坏短期连续排序收益；14:01 的 `<1x` 表示 Top100 已低配最终涨停股。
- 当前 Rank IC、Top100 总超额和非最终涨停贡献已强烈支持普通股票上的 1m 排序能力；若要进一步声称
  “全分位平滑单调”，仍需补做仅保留非最终涨停股票的分位收益曲线。
